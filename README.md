# 🏏 IPL 2022 Capstone Project

A data analysis project exploring IPL 2022 match-level data to derive insights on team performance, player stats, and match outcomes.

## 📊 Dataset
The dataset (`IPL.csv`) contains match-level records with columns including:
`date`, `venue`, `stage`, `team1`, `team2`, `toss_winner`, `toss_decision`,
`first_ings_score`, `second_ings_score`, `match_winner`, `won_by`, `margin`,
`player_of_the_match`, `top_scorer`, `highscore`, `best_bowling`, and more.

## 🔍 Key Questions Explored
- How do teams win — by wickets or runs?
- Which player has the highest score?
- How does the toss impact match results?
- Who are the top performers across the season?

## 🛠️ Tech Stack
- Python 3.14
- Pandas
- NumPy
- Seaborn
- Jupyter Notebook

## 🚀 Getting Started
